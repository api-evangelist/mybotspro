# myBots (Mia AI)

> Enterprise AI sales and support agents for WhatsApp, Instagram, Telegram and web chat, operated by Global AI Group, Inc. An agent qualifies inbound leads, answers from the business's own knowledge base, books appointments, and syncs contacts to a CRM. myBots does NOT publish a public API, OpenAPI definition, SDK, developer portal or documented webhook surface. This file was generated by API Evangelist from probed evidence, not copied from the provider — myBots serves no llms.txt of its own.

## What is actually callable

- [OpenID Connect discovery](https://auth.mybots.pro/.well-known/openid-configuration): Live, anonymous OIDC/OAuth 2.0 metadata for the myBots identity server (OpenIddict). The only complete machine-readable contract myBots publishes.
- [OAuth 2.0 authorization server metadata](https://auth.mybots.pro/.well-known/oauth-authorization-server): RFC 8414 document, same payload as the OIDC one.
- [JWKS](https://auth.mybots.pro/.well-known/jwks): Signing keys. Note the non-standard path — /.well-known/jwks.json returns 404.
- [Web chat channel config](https://notification.mybots.pro/api/IntegrationApp/public/webchat/): GET /{channel}/config?source=widget. The one anonymous product API operation; returns accentColor, launcherIcon and a handshake token. Authorized by a per-channel domain allow-list, not a token.
- [Tenant API](https://client.mybots.pro): Bearer-gated (401 www-authenticate: Bearer). No specification, reference or endpoint list is published.
- [Web chat widget loader](https://mia.mybots.pro/widget.js): First-party embeddable script. Usage and every attribute are documented in a comment inside the file itself and nowhere else.

## What does not exist

- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI or Postman collection on any host (all probed 2026-08-14).
- No MCP server and no A2A agent card.
- No SDK on npm, PyPI, RubyGems, crates.io, NuGet, Maven Central or pkg.go.dev; no GitHub organization.
- No developer portal, API reference, changelog, status page, security.txt or deprecation policy.
- Caution for crawlers: https://mybots.pro answers HTTP 200 with the same HTML shell for EVERY path, including /openapi.json, /llms.txt and every /.well-known/ path. Those 200s are soft-404s and carry no document.

## Product

- [myBots](https://mybots.pro): Product site. Channels: WhatsApp, Instagram, Telegram, LinkedIn, web chat. Integrations named: HubSpot, Bitrix, Pipedrive, amoCRM, Google Sheets, Google Calendar, Calendly.
- [Mia AI application](https://mia.mybots.pro): Tenant application and sign-in.
- [Pricing](https://mybots.pro/#pricing): Solo $25/mo, Lite $49/mo, Pro $99/mo, Agency $290/mo, Enterprise custom. Metered on messages per month, not seats. No plan includes API access.
